# Changelog

Every notable change to the leaf workspace, newest first. The crates share one
version number and one release, so this is the changelog for all of them; the
scope on a bullet (`**core**`, `**leaf-swift**`) says which surface moved.

The `## Unreleased` region below is generated by `cargo xtask changelog --write`
from the commits since the last tag, and `cargo xtask release` cuts it into a
released section. Everything outside that region is handwritten and stays that
way — including a release intro, when a release wants a narrative rather than a
list. **Behavioural changes** is generated too, from `Behavioural-change:`
trailers on the commits themselves; write one on any commit an embedder would
notice after upgrading without editing a line of their own code.

Not every crate in the workspace reaches crates.io, and `cargo xtask publish`
says which and why on every run. `leaf-gpui` and the `leaf` app pin gpui to a Zed
commit, and crates.io accepts no upload carrying a git dependency; `leaf-wasm` is
built by wasm-pack into an npm package rather than published as a crate; the name
`leaf` on crates.io has belonged to an unrelated 2016 machine-learning framework
since long before this one. So a release publishes `leaf-core`, `leaf-ffi`,
`leaf-ratatui`, and `leaf-tui`, and tags the rest.

One irregularity, recorded rather than tidied away: **leaf-core 0.1.0 and
leaf-ffi 0.1.0 went to crates.io on 2026-08-17 by hand**, and `leaf-ratatui` and
`leaf-tui` did not go at all. The `v0.1.0` tag covers all of them either way —
it is at `e32cc88`, the same day. Everything from `v0.2.0` on goes up through
`cargo xtask publish`.

### Behavioural changes

- On iOS, a blockquote's gutter now widens with the reader's
Dynamic Type setting instead of staying at `EditorTheme.quoteIndent`, so quoted
text wraps in a different place at any non-default content size.

- `LeafFormattingToolbar` now scales its glyphs, targets, and
height with Dynamic Type (capped at 1.6x). A host that laid the `.bar` style
out inside a fixed-height container should give it room to grow.

- The `LeafEditor(model:accessory:)` keyboard accessory is
sized to its content rather than to a fixed 44pt, with 44 as the floor. An
accessory that relied on being cropped to 44 will now be shown in full.


## v0.1.0 — 2026-08-17

The first tag, and the first crates.io upload. leaf reached it over 181 commits
made before this changelog existed, so the git log is the record for everything
up to here rather than a list in this file.

What the tag names: `leaf-core`, the frontend-neutral document model — a
byte-offset caret and selection over twig's round-trippable AST, plus the
AST→glyph map that every frontend renders from, styled with a toolkit-agnostic
`Style`. Around it, four frontends over that one model: `leaf-ratatui` (the
terminal widget, with block images through the terminal's own graphics
protocol), `leaf-gpui` (the gpui widget), `leaf-ffi` (the UniFFI/Swift binding
behind `packages/leaf-swift`), and `leaf-wasm` (the browser binding). And two
hosts: `apps/leaf-tui` and `apps/leaf`.

`leaf-core` and `leaf-ffi` went to crates.io at this version; the others did
not.
